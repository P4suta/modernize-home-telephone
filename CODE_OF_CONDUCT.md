# Code of conduct

Participants must treat other people respectfully and discuss technical disagreements using evidence and specific behavior.
Harassment, threats, discriminatory abuse, sexualized conduct, and disclosure of another person's private information are unacceptable.
Apply the same standards in issues, pull requests, reviews, and other project discussions.

Maintainers may edit or remove harmful contributions and restrict participation to protect other participants.
For a moderation request without private details, open an issue identifying the relevant public discussion.
Use [GitHub's abuse reporting process](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) for abuse that requires a private report to GitHub.
Don't repeat private information or harassment in a public moderation request.
