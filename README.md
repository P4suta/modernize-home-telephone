# Home Telephone

Programmable home telephone software for HT813 gateways and Raspberry Pi.

## Installation

```sh
mise install
mise x -- pnpm --dir web install --frozen-lockfile --ignore-scripts
```

## Usage

```sh
mise x -- just lab
```
